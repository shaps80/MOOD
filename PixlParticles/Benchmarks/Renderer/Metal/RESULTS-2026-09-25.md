# Provisional GPU renderer results — 2026-09-25

Apple M4 Pro, macOS host, native Release SwiftPM and production Metal shaders.
Workload: 2,000,000 particles, seeded sphere surface, frozen simulation,
2852 × 1916 pixels, default point/billboard configurations, diagnostics enabled.
Each path: 30 warmup frames, 180 measured frames, serial completion. Offscreen
RGBA16Float target and normal production depth attachment; no editor guides.
The existing editor was suspended to avoid concurrent GPU work. These are GPU
elapsed times, not editor FPS or an end-to-end application memory measurement.

| GPU total | Reference median | Automatic median | Reference p95 | Automatic p95 |
| --- | ---: | ---: | ---: | ---: |
| Points, run 1 | 7.356 ms | 0.994 ms | 8.534 ms | 1.495 ms |
| Points, run 2 | 7.317 ms | 0.995 ms | 8.626 ms | 1.633 ms |
| Billboards, run 1 | 10.361 ms | 10.268 ms | 11.671 ms | 11.577 ms |
| Billboards, run 2 | 10.440 ms | 10.477 ms | 11.877 ms | 11.989 ms |

Point median reduction: 86.4–86.5%. Billboard code is unchanged; timings remain
within run-to-run variation. The new point path adds 43,715,456 bytes of reusable
GPU scratch at this viewport (8 bytes/pixel), plus a 4-byte width constant. Total
application memory was not measured, so do not infer its change from scratch size.

An additional white-palette comparison differed at 38 dense point pixels;
billboards matched exactly. Differences occur at subpixel raster boundaries.
No simulation state, particle count, or spatial detail is reduced. Compute
rasterization is not promised to match fixed-function rounding bit-for-bit.

## Reproduce

Run `.scripts/benchmark-rendering run 2000000 2852 1916` sequentially twice,
without another GPU workload. Run `.scripts/benchmark-rendering run validate`
for colour image comparisons. Both use real production code. Shader-load or
counter failures must not be reported as zero GPU time. Capture-only timings are
not performance evidence.

macOS Release editor build succeeded. Seven isolated renderer tests passed.
Full package tests remain blocked by pre-existing obsolete System initializer
calls in particle tests. Editor visual acceptance is still pending.
